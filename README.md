# I Really Like Slop

A Claude skill that rewrites plain prose to sound like peak LLM output.
It is the inverse of [stop-slop](https://github.com/hardikpandya/stop-slop).

Use it for parody, satire, and jokes. Do not use it on sincere writing.

## Install

Copy this folder to `~/.claude/skills/i-really-like-slop/`. Then run
`/i-really-like-slop` and paste some text.

## What it adds

- Throat-clearing openers ("Here's the thing:")
- Binary contrasts ("It's not X. It's Y.")
- Triplets, em dashes, and bold lead-ins
- False agency ("the data tells us")
- Vague declaratives ("The implications are significant.")
- The word "provenance," where it fits
- A closing offer of more help

## Files

- `SKILL.md`: rules, process, quick checks, scoring
- `references/phrases.md`: phrases and vocabulary to add
- `references/structures.md`: structures to add
- `references/examples.md`: before/after rewrites
